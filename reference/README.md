# Reference fixtures

This directory contains third-party Moonshot files used by tests as a golden
encoder oracle or retained as architecture reference material.

- They are not imported by the `k3` runtime.
- They are not included in the `k3` wheel.
- They are not relicensed under the project's Apache-2.0 licence.
- Changes must preserve the upstream behavior needed by the oracle and update
  the source revision, file relationship, and licence record in
  [PROVENANCE.md](PROVENANCE.md).

Read [PROVENANCE.md](PROVENANCE.md) before copying, modifying, or redistributing
anything in this directory.
